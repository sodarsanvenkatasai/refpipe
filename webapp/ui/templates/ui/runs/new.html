What happens when you run

  1. IngestCSV is read raw; column names are checked before any row is processed.
  2. ValidateFirst failure wins: format → id → code → status → effective date → entity.
  3. QuarantineRejected rows keep their raw payload, reason and source position.
  4. PublishValid rows are upserted on record_id in a single transaction.
  5. ReconcileCounts are verified before the run is marked successful.
A failed publish rolls back completely — rerunning with the same input is always safe.

Before you start

Reference versions are immutable: the same name with different content is refused. Pick an existing version, or provide a new one together with its CSV.
